SharedSpend
SharedSpend is a web-based expense tracking application designed for families or groups. The app allows multiple members to log in, set a shared monthly budget, and track expenses with an easy-to-use dashboard. 
Each account can have up to 6 members, and the app provides a comparison between the total monthly budget and actual expenses, along with a visual breakdown in the form of a pie chart.

Features
 > User Registration and Login System
 > Multi-member Account Support (up to 6 members per account)
 > Add, View, and Edit Expenses
 > Set Monthly Budget (only at the beginning of each month)
 > Pie Chart visualization for expense categories
 > Comparison between monthly budget and total expenses
 > Notifications when the budget is exceeded
 >Responsive and visually appealing dashboard
 >Dark theme with black and red color scheme
 > Smooth animations and interactive UI elements
Tech Stack
 > Backend: Django (Python)
 > Frontend: HTML, CSS, JavaScript (with animations), and Bootstrap
 > Database: SQLite (Django's default database)
 > Charts: Chart.js for visualizing expenses in a pie chart
